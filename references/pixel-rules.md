# 像素規則

## 格子(最重要:不能有半格)

- 畫面 1080×1920 = **180×320 格,一格 6px**。背景、角色、道具處理後都是 6px 一格。
- 所有位置、位移都用 6 的倍數(模板的 `snap()`);放大只能整數倍(`k: 2`、`k: 3`)。
- 動畫一律 GSAP `ease: "steps(n)"`,一步剛好走一格;不要用 power / sine 這類平滑緩動。
- 換動作 = 切換不同的動作格圖片,不要用 CSS 縮放、旋轉角色(會糊、格子不齊)。唯一例外是左右翻面(`scaleX(-1)`,整數倍不會糊)。
- 圖片一律 `image-rendering: pixelated`。

## 顏色

- 場景 96 色(48 色會把霓虹的粉紅、藍色吃掉);角色、道具每張 40 色。
- 字只用一個強調色(模板 `--accent: #FFD166`),其他字白色;場景本身可以很花。
- 可以疊一層淡掃描線(`#scan`)和暗角(`#vig`),增加 CRT 感。

## 字

- 中文:**俐方體 11 號 Cubic 11**,字級用 11 的倍數(44、66)。
- 英文數字:**Press Start 2P**,字級用 8 的倍數(24、32、48、64)。
- 外框用「硬邊」:8 個方向各偏 6px(或 4px)的實色 text-shadow(`.o6`、`.o4`),不要用模糊陰影。
- 字幕一句一條、句尾標點拿掉;太長自動縮字(模板以 14.5 個全形字為上限)。

## 版面(直式)

| 區塊 | 位置 |
|---|---|
| 浮水印 | 右上 |
| 段落標題 | y 210 附近(英文點陣字 + 中文) |
| 主體 | y 400–1440 |
| 角色腳底 | y 1260–1440 |
| 字幕 | y 1500 |
| 最下面 300px | 留給 App 的按鈕與文案,不放重要東西 |

## 場景與容器

- 場景、道具容器用 `opacity` 藏,不要用 `visibility`(子元素自己被設成 visible 時,父層的 hidden 擋不住,會穿到別的場景)。
- 前景遮後景:場景生成時把天空畫成純洋紅(`"key": true`),處理後天空透明,後面就能放星空、K 線、會動的雲。
- 60 秒約 6 個地點,一段一景;地點裡多放會動的小東西,比一直換場景好看。
- 特效轉場只用一種(方塊轉場),太多種會亂。

## 交片前的檢查表

渲染後拼縮圖表(`ffmpeg -i x.mp4 -vf "fps=1/0.7,scale=270:480,tile=7x4" -frames:v 1 sheet.jpg`)逐格看:

- [ ] 沒有糊掉的像素、沒有半格錯位(放大看角色邊緣)
- [ ] 角色換動作時不會跳位置;走路腳有交替
- [ ] 字沒有被角色或道具擋住;字幕不壓到主體
- [ ] 換場時前一個場景的東西沒有殘留
- [ ] 每 1.5 秒內畫面有東西在動;重點畫面停得夠久
- [ ] 音效對上動作(落地、打字、跳號);聽一次全片
- [ ] 規格:1080×1920、60fps、有聲音軌(`ffprobe`)
